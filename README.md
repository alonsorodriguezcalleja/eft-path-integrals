# Effective Field Theories and Functional Methods

This repository contains the manuscript and theoretical derivations for a seminar project on Effective Field Theories (EFTs), supervised by Dr. Verónica Sanz at the Department of Theoretical Physics, Universidad de Valencia. 

The project presents a formal, pedagogical approach to EFTs, focusing on the fundamental mechanisms used to decouple high-energy scales in quantum field theories.

## 📖 Project Overview

The manuscript explores the following key concepts:
* **Symmetry-Driven Construction:** The foundational principles of building generic Lagrangians dictated by the underlying symmetries of a system.
* **Path-Integral Formalism:** A rigorous development of functional methods to integrate out heavy degrees of freedom.
* **Toy Model Application:** The application of this mathematical machinery to a concrete system of two coupled scalar fields, explicitly illustrating the generation of effective operators.
